    掘削手順The drill method

    Every job runs in the same order. Break the order and two people's code collides.

    1. 01

      Pull

      Every session starts with git pull. Two of us share one repo, so conflicts get stopped before they start.

    2. 02

      Write in files

      Code is written in files, not in Studio, and flows into Studio through Rojo.

    3. 03

      Clean up

      After every change, StyLua formats the code and Selene catches mistakes.

    4. 04

      Only what's asked

      On client work, only what was requested changes. If something else catches my eye, I ask first.

    5. 05

      Ship

      A short commit that says what changed, then push.
